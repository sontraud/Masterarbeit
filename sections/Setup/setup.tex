\chapter{\MP method parameters and Simulation Setup}
\label{ch:simSetup}

Building upon the implementation discussed in the previous chapter we now discuss how to initialize a case.
We examine the available modeling options and files necessary for simulation.
We discuss the setup of our simulation used for comparison of experimental data and simulation results, done in the following chapter.
%The data, kindly provided by the "Division of Combustion Technology" of the "Engler-Bunte-Institute" \footnote{\url{https://vbt.ebi.kit.edu/english/21_1186.php}} are based on a simplified fluidized bed reactor.
This includes the computational grid where we look at the convergence for different cell lengths and the boundary conditions used.

\section{\OF \MP method files}
\subsection{\lstinline|kinematicCloudProperties|}
The particles are modeled as a kinematic Cloud with properties set in \lstinline|kinematicCloudProperties|.
This section details the parameters and models that can be adjusted.

The first property we can configure is the maximum Courant number \lstinline|maxCo| that is used in the Lagrangian time step fraction, see listing \ref{code:stepFraction}.
Constant physical properties, specifically the fluid density \lstinline|rho0| and the maximum packing fraction \lstinline|alphaMax| are set. 
The latter is used in \lstinline|createFields| to set the minimum fluid volume fraction that is allowed per cell 
\begin{equation*}
    \fvf_{min} = 1- \fvf_{max}
\end{equation*}
used in equation \eqref{eq:maxAlpha}.
Particle dynamics are influenced by the Drag force model and particle injection in \lstinline|subModels|. 
In \ref{sec:MPLoop} two drag models are discussed: \lstinline|ErgunWenYuDrag| and \lstinline|PlessisMasliyahDrag| which will be evaluated in the next chapter \ref{sec:paramStudy} as they have an influence on both the fluid and the particulate phase.
The particles are either initialized inside the reactor at time step $0$ by \lstinline|manualInjection|, where particle positons are defined in \lstinline|kinematicCloudPositions|, or injected by \lstinline|patchInjection|.
For the latter we define a patch through which the particles are injected over a set time.
For both injection models we can set a particle velocity at injection and distribution for the particle diameters.
With \lstinline|nParticle| we set the number of particles in one parcel, as explained in sec \ref{sec:PartGrouping}.

Particle-boundary interactions are specified in \lstinline|localInteraction|, where we define each patches' restitution coefficient \lstinline|e| and friction coefficient \lstinline|mu|.

The packing model defines which particle normal stress model we use. In section \ref{sec:MPLoop} we discussed the explicit Harris and Crighton model.
Further models implemented in \OF are the implicit Harris and Crighton model or the explicit or implicit Lun model.
For the explicit Harris and Crighton model, the parameters are the close packed volume fraction $\pvfcp$ as \lstinline|alphaPacked|, \lstinline|pSolid| as the pressure constant $P_s$, \lstinline|beta| as the exponent $\beta$ and \lstinline|eps| as the small constant limiting used for avoiding singularities.
Additionaly, we can also add a correction limiting method with the parameter \lstinline|e| which is given by equation \eqref{eq:correctLimiting}.
A collision damping model can be applied by setting \lstinline|dampingModel| to \lstinline|relaxation|. 
In our later simulations it is always set to \lstinline|none| and therefor not applied.

The return-to-isotropy model is turned on by setting \lstinline|isotropyModel| to \lstinline|stochastic| and turned off by setting it to \lstinline|none|.
This model uses the radial distribution function $g_0$ defined in \ref{eq:rtiSol} which utilizes the close-pack volume fraction \lstinline|alphaPacked|.
Along with the elasticity factor \lstinline|e|, see $\eta$, both are used to determine the relaxation time $\ss_G$ in equation \eqref{eq:DampingTimeG}.
The impact of the isotropy model is discussed in sec \ref{sec:returnToIsotropyImpact}.

\section{Simplified fluidized bed reactor}
For better comparison the experiments were done on in a cylindrical tube with a porous mesh at the bottom.
The bed consists of glass beads of a diameter of $40 \mu m$ to $70 \mu m$, chosen to be similar to the iron particles in \cite{Malte}.
The size distribution was unknown at the time of simulation and therefor assumed to be uniformly distributed.
Figure \ref{fig:glassBeats} shows the experiment at two different inlet velocities.

    \hfill

    \caption{Fluidized bed with glass beads at $u = 0.006m/s$ and $0.06m/s$ inlet velocity}
    \label{fig:glassBeats}
\end{figure}

The experimental bed is $1 \operatorname{cm}$.
In the simulation this is replicated using $N_p$ particles based on the close pack volume fraction of $\pvfcp = 0.65$.
Because the \MP method models particles only as point masses rather than resolved spheres with a volume we do not face sphere packing problems and can therefor calculate the number of particles with a diameter $d$ for a bed height $h_{bed}$ and a bed area of $A_{bed}$ as
\begin{equation*}
    0.65  A_{bed} h_{bed} = \dfrac{4}{3} \pi \left( \dfrac{d_p}{2} \right)^3 N_p
    \Leftrightarrow 
    N_p = \dfrac{3}{4 \pi} \left( \dfrac{2}{d_p} \right)^3 0.65  A_{bed} h_{bed}.
\end{equation*}
The particles are initialized up to a height $25 \operatorname{mm}$ spaced out equidistantly in a grid with no velocity.

\section{Experimental Bed height}
\label{sec:bedHeightBest}
To validate the simulation results, the experimental bed height is extracted from the images set to grayscale.
We start by cropping the images to isolate the reactor tube, see \ref{fig:img_processing}.
We iterate over each column of pixels, starting from the top.
For each column we identify the bed height by iterating over each pixel and saving it if the following three conditions apply.
First we calculate the gradient based on the current pixel and the one below and save the current pixel if it has the largest gradient.
Second gradient must be positive, therefor we are entering a lighter region as to not exit the bed.
Lastly, to reduce the error of identifying smudges and noise as a bed we set a minimum brightness value of $120$.
The bed heights of each column are averaged to determine the mean bed height.

\section{Grid}
The experimental data indicates a maximum mean bed height of approximately $2.5 \operatorname{cm}$. To account for particle fluctuations and bed expansion, we extend  simulation domain to a height of $5 \operatorname{cm}$. The domain width is adapted to the simplified fluidized bed geometry width of $1 \operatorname{cm}$.
To reduce computation time we effectively model the reactor as 2d by modeling a cuboid with the above described dimensions and a depth of $0.1 \operatorname{cm}$.
The mesh consists of cubes. 
In the following we conduct a grid sensitivity study by varying the cube side length $\Delta \x$ from $2 d_p$  up to $20 d_p$, as detailed in table \ref{tab:grid_sizes}.

To quantify the discretization error we use the absolute and relative $L_1$ and $L_2$ errors summed over $N$ time steps..
The absolute $L1$-error and its time-averaged counterpart are defined as
\begin{equation}
\label{eq:l1error}
    err_{L1} =\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert \qquad err_{L1,mean} = \dfrac{1}{N}\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert,
\end{equation}
and the relative $L1$-error as
\begin{equation}
\label{eq:l1relerror}
    err_{L1,rel} = \dfrac{\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert}{\sum_{i=1}^N \lvert h_{ref,i} \rvert} \qquad  err_{L1,rel, mean} = \dfrac{1}{N} \dfrac{\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert}{\sum_{i=1}^N \lvert h_{ref,i} \rvert}.
\end{equation}
Similarly we look at $L2$-errors which are more sensitive to outliers with the absolute $L2$-error
\begin{equation}
\label{eq:l2error}
    err_{L2} = \sqrt{\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert^2} \qquad err_{L2,mean} = \dfrac{1}{N}\sqrt{\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert^2}
\end{equation}
and the relative $L2$-error
\begin{equation}
\label{eq:l2relerror}
    err_{L2,rel} = \dfrac{\sqrt{\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert^2}}{\sqrt{\sum_{i=1}^N \lvert h_{ref,i} \rvert^2}} \qquad err_{L2,rel,mean} = \dfrac{1}{N}\dfrac{\sqrt{\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert^2}}{\sqrt{\sum_{i=1}^N \lvert h_{ref,i} \rvert^2}}.
\end{equation}

As we can see in figure \ref{fig:l1error}, in which the $L1$-error is depicted, we can see that the error for $\Delta \x = 0.33 \operatorname{mm}$ increases rapidly during the initial fall of the particles.
In contrast, the error for $\Delta \x = 0.5 \operatorname{mm}$ rises moderately at first and later accelerates. A consistently small error is achieved by $L1$-error of cell length $0.25 \operatorname{mm}$.

As expected refining the grid reduces the error. To investigate the convergence we look at the estimated order of convergence
% \begin{equation*}
%     EOC =\dfrac{\lvert L1_{0.25}- L1_{0.33} \rvert}{\lvert L1_{0.33}- L1_{0.5} \rvert} = \dfrac{\lvert 0.00498634584254441-0.022492365778959397 \rvert}{\lvert 0.022492365778959397-0.03705231627423083\rvert}\approx 1.2.
% \end{equation*}
\begin{equation*}
    EOC_{\Delta x_1,\Delta x_2} = \dfrac{\log \left( \frac{h_1 - h}{h_2 -h} \right)}{\log \left( \frac{\Delta x_1}{\Delta x_2} \right)}.
\end{equation*}
Plugging in values for our case we then have
\begin{align*}
    EOC_{0.5,0.33} &= \dfrac{\log \left( \frac{0.03705}{0.02249} \right)}{\log \left( \frac{0.5}{0.33} \right)} = 0.97715
    \qquad EOC_{0.33,0.25} = \dfrac{\log \left( \frac{0.02249}{0.00499} \right)}{\log \left( \frac{0.33}{0.25} \right)} =5.42615%\\
    %EOC_{ges} &= \dfrac{EOC_{0.5,0.33} + EOC_{0.33,0.25}}{2} = 3.20165
    %\qquad &EOC_{0.5,0.25} = \dfrac{\log \left( \frac{0.03705}{0.00499} \right)}{\log \left( \frac{0.5}{0.25} \right)} = 2.89351.
\end{align*}
We estimate the overall order of convergence by a linear fit calculated via \lstinline|numpy.polyfit|. The slope, which is our estimated order of convergence, here is about $2.76073$. We also fit a line to the grid points $0.5$ and $0.25$ which has a slope of $2.89351$.



Overall we observe that the error of cell length $\Delta x = 0.33 \operatorname{mm}$ grows rapidly at first and later more gradually.
The corresponding mirrored behavior can be observed for  a cell length of $\Delta x = 0.5 \operatorname{mm}$ which grows moderately at first and then more rapidly.
To avoid both behaviors we rule out both cell length.
The grid size $\Delta x = 0.25$ offers the best compromise between simulation costs and error. For grid length $\Delta x = 0.25$ the simulation on average takes $11824s$ per simulation second and $19614s$ for $\Delta x = 0.2 mm$.

We note that due to the averaging methods applied the error grows for smaller cell lengths. We can see this behavior for $\Delta \x = 0.1 \operatorname{mm}$.

The final mesh dimensions are $10 \operatorname{mm} \times 0.25 \operatorname{mm} \times 50 \operatorname{mm}$ and is depicted in figure \ref{fig:grid}.

\section{Boundary conditions}
After generating our mesh we assign boundary conditions for both the fluid and the particulate phase. The domain consists of an inlet at the bottom, an outlet at the top, no-slip walls on the sides, and symmetry planes for the front and back.


The gas inlet at the bottom of the grid is set to \lstinline|interstialVelocityInlet| which scales the inlet velocity based on the volume fraction of air
\begin{equation*}
    \uf = \dfrac{\u}{\fvf}.
\end{equation*}
Consequently the inlet fluid inlet velocity is always equal or greater than the set velocity.
If no particles are in the cell at the inlet the velocity remains as set. This ensures the correct phase flux.
The top is a \lstinline|pressureInletOutletVelocity| therefor a zero gradient outlet for outflow and a fixed-value condition set to zero for the backflow.
The pressure at the top is set to zero.
The pressure of the inlet and the walls on the left and right side of the grid are set to \lstinline|fixedFluxPressure| with the gradient being set to zero.


For the particulate phase we set the inlet as well as the all other boundaries except the top to rebound.
The top is left as escape to allow particles to exit the reactor.
The front and the back are connected through \lstinline|symmetry| for both the pressure and the velocity.
