\section{Simplified Fluidized Bed Reactor}
For better comparison, experimental data that was provided was gathered in a cylindrical tube with a porous mesh at the bottom.
The bed consists of glass beads with a diameter of $40 \operatorname{\mu m}$ to $70 \operatorname{\mu m}$, chosen to be similar to the iron particles in \cite{Malte}.
The size distribution was unknown at the time of simulation and therefore assumed to be uniformly distributed.
Figure \ref{fig:glassBeats} shows the experiment at two different inlet velocities.

The initial experimental bed height is $1 \operatorname{cm}$.
In the simulation, this is replicated using $N_p$ particles based on the close pack volume fraction of $\pvfcp = 0.65$.
Because the \MP method models particles only as point masses rather than resolved spheres with a volume, we do not face sphere packing problems and can therefore calculate the number of particles with a diameter $d$ for a bed height $h_{bed}$ and a bed area of $A_{bed}$ as
\begin{equation*}
    0.65  A_{bed} h_{bed} = \dfrac{4}{3} \pi \left( \dfrac{d_p}{2} \right)^3 N_p
    \Leftrightarrow 
    N_p = \dfrac{3}{4 \pi} \left( \dfrac{2}{d_p} \right)^3 0.65  A_{bed} h_{bed}.
\end{equation*}
For the simulation, we calculate the needed particles for a bed height of $h_{bed} = 1 \operatorname{cm}$. We initialize them so, that they are equidistantly spaced up to a height of $2.5 \operatorname{cm}$ in a grid with no initial velocity.

\section{Processing Provided Experimental Data}
\label{sec:bedHeightBest}
The provided data consists of two data sets. 
The first data set is a collection of videos that show the glass beads at different inlet velocities, which we will use in the following to gather a bed height.
We extract the experimental bed height from the provided images converted to grayscale.
We start by cropping the images to isolate the reactor tube, see Fig. \ref{fig:img_processing}.
We iterate over each column of pixels, starting from the top.
For each column, we identify the bed height by iterating over each pixel and saving it if the following three conditions apply.
First, we calculate the gradient based on the current pixel and the one below and save the current pixel if it has the largest gradient.
A large gradient may indicate either entering or exiting a bed. To only look at the former cases, the gradient must be positive.
Lastly, to reduce the likelihood of identifying smudges and noise as part of the bed, we set a minimum brightness value of $120$.
The bed heights of each column are averaged to determine the mean bed height.

\section{\OF \MP Method Modelling Parameters}
The particles are modeled as a kinematic cloud with properties set in \lstinline|kinematicCloudProperties|.
This section details the parameters and models that can be adjusted.

The first property we can configure is the maximum Courant number \lstinline|maxCo|, which is used in the Lagrangian time step fraction, see Lst. \ref{code:stepFraction}.
Constant physical properties, specifically the fluid density \lstinline|rho0| and the maximum packing fraction \lstinline|alphaMax| are set. 
The latter is used in \lstinline|createFields| to set the minimum fluid volume fraction that can be reached by a cell
\begin{equation*}
    \fvf_{min} = 1- \fvf_{max}
\end{equation*}
used in equation \eqref{eq:maxAlpha}. If the fluid volume fraction reaches a lower value, it is set to $\fvf_{min}$ for stability. This can lead to fluid volume fraction that do not reflect the current number of particles in a cell.
Particle dynamics are influenced by the drag force model and particle injection in \lstinline|subModels|. 
In sec. \ref{sec:MPLoop}, two drag models are discussed: \lstinline|ErgunWenYuDrag| and \lstinline|PlessisMasliyahDrag|, which will be evaluated in the next Sec. \ref{sec:paramStudy}, as they have an influence on both the fluid and the solid particle phase.
The particles are either initialized inside the reactor at time step $0$ by \lstinline|manualInjection|, where particle positions are defined in \lstinline|kinematicCloudPositions|, or injected by \lstinline|patchInjection|.
For the latter, we define a patch through which the particles are injected over a set time.
In the following, we only use \lstinline|manualInjection|.
For both injection models, we can set a particle velocity at injection and a distribution for the particle diameters.
With \lstinline|nParticle|, we set the number of particles in one parcel, as explained in Sec. \ref{sec:PartGrouping}.

Particle-boundary interactions are specified in \lstinline|localInteraction|, where we define the interaction for each patch. For an outlet, we can use \lstinline|escape|, which removes particles from the domain.
For walls we can use \lstinline|rebound| with patches' restitution coefficient \lstinline|e| and friction coefficient \lstinline|mu|.
We consider a particle with velocity $u_{p,0}$ prior to the wall interaction, with a tangential velocity $u_{p,t}^0 = u_{p}^0 \sin ( \phi)$ and a normal velocity $u_{p,n}^0 = u_{p}^0 \cos ( \phi)$, with the impact angle $\phi$, relative to the wall normal, as in Fig. \ref{fig:wall_interaction}. The particle velocity after the wall interaction is then given by the tangential and normal velocities
\begin{equation}
    u_{p,n}^1 = - e u_p^1 \cos (\phi) \qquad u_{p,t}^1 = (1- \mu) u_{p}^0 \sin (\phi).
\end{equation}
which sum to the particle velocity after impact $\up^1$.
The coefficients are given in the \lstinline|Goldschmidt| tutorial as $e = 0.97$ and $\mu = 0.09$, therefore, in our case, the particle is decelerated in both directions, but more so in the tangential direction.

The packing model defines which particle normal stress model we use. In Sec. \ref{sec:MPLoop}, we discussed the explicit Harris and Crighton model.
Further sub-models, which can be turned on instead and are implemented in \OFns, are the implicit Harris and Crighton model or the explicit and implicit Lun model.
For the explicit Harris and Crighton model, the parameters are the close packed volume fraction $\pvfcp$ as \lstinline|alphaPacked|, \lstinline|pSolid| as the pressure constant $P_s$, \lstinline|beta| as the exponent $\beta$ and \lstinline|eps| as the small constant used for avoiding singularities.
Additionally, we can also add a correction limiting method with the parameter \lstinline|e|, which is given by Eq. \eqref{eq:correctLimiting}.
A collision damping model can be applied by setting \lstinline|dampingModel| to \lstinline|relaxation|. 
In our later simulations, it is always set to \lstinline|none| and therefore not applied, see Sec. \ref{sec:DampResults}.

The return-to-isotropy model is turned on by setting \lstinline|isotropyModel| to \lstinline|stochastic| and turned off by setting it to \lstinline|none|.
This model uses the radial distribution function $g_0$ defined in Eq. \eqref{eq:rtiSol}, which utilizes the close-pack volume fraction \lstinline|alphaPacked|, along with the elasticity factor \lstinline|e|, which differs from the restitution coefficient \lstinline|e| defined above.
The elasticity factor is included in
\begin{equation}
    \eta = \dfrac{1+e}{2},
\end{equation}
which is used along with the close packed particle volume fractions in eq. \eqref{eq:DampingTimeG} for determining the relaxation time.
The impact of the isotropy model is discussed in Sec. \ref{sec:returnToIsotropyImpact}.

\section{\lstinline|Goldschmidt| Case}
\label{sec:goldschmidt}
A tutorial for the \MP method in \OF is given by the \lstinline|Goldschmidt| tutorial, which is based on experiments and data collected by Mathijs Goldschmidt \cite{standardGoldschmidt}.
The case is pseudo two-dimensional with a domain of $1.5 \operatorname{cm} \times 15 \operatorname{cm} \times 45c \operatorname{cm}$ and a grid of $1 \times 15 \times 45$ cells.
The case here was used as a starting point for simulations and was then modified to fit the experimental setup.
$24750$ particles with a diameter of $2.5 \operatorname{mm}$ are inserted distributed uniformly up to a bed height of $29.5 \operatorname{cm}$.
The inlet velocity is set to $1.875 \operatorname{m/s}$.
%The boundary conditions are mostly identical to the ones we will use for our simulations later except for the interactions of the particles with the top of the domain which is set to \lstinline|escape| in our later simulations, allowing particles to flee the reactor while in the \lstinline|Goldschmidt| case it is shares the same patch interaction models as the walls, \lstinline|rebound|.
The remaining parameters are chosen as in Tab. \ref{tab:goldschmidt}.

         \hline
         \lstinline|Goldschmidt|& \texttt{explicit} & \lstinline|HarrisCrighton| & $0.65$ & $10$ & $2.0$

The boundary conditions are mostly identical to the ones we will use later in our simulations.
The domain consists of an inlet at the bottom, an outlet at the top, no-slip walls on the sides, and symmetry planes for the front and back.
The gas inlet at the bottom of the grid is set to \lstinline|interstialVelocityInlet|, which scales the inlet velocity based on the volume fraction of air
\begin{equation*}
    \uf = \dfrac{\u}{\fvf},
\end{equation*}
because it is based on the phase volumetric flux $\fvf \uf$.
Consequently, the inlet fluid velocity is always equal to or greater than the set velocity.
If no particles are in the cell at the inlet, the velocity remains as set. This ensures the correct phase flux.
The boundary at the top of the domain is a \lstinline|pressureInletOutletVelocity|, therefore a zero gradient outlet for outflow and a fixed-value condition set to zero for the backflow.
The pressure at the top is set to zero. The \MP solver is incompressible, therefore we only solve for the gradient of the pressure and the pressure is only unique up to a constant.
We set the constant at the top of the reactor to zero.
In our parameter study, we only look at the pressure drop and can therefore omit the constant.
The pressure of the inlet and the walls on the left and right side of the grid are set to \lstinline|fixedFluxPressure| with the gradient being set to zero.

For the solid particle phase, we connect the front and the bottom through \lstinline|symmetry| for both the pressure and the velocity.
In the \lstinline|Goldschmidt| case, all other boundaries, including the top and the bottom, as well as the sides, are set to \lstinline|rebound|.
In our simulations, we will set the top to \lstinline|escape| to allow particles to exit the reactor.

\section{Grid Setup}
The experimental data indicates a maximum mean bed height of approximately $2.5 \operatorname{cm}$. To account for particle fluctuations and bed expansion, we extend the  simulation domain to a height of $5 \operatorname{cm}$. The domain width is adapted to the simplified fluidized bed geometry with a width of $1 \operatorname{cm}$.
To reduce computation time, we effectively model the reactor as 2D by modeling a cuboid with the above described dimensions and a depth of $0.1 \operatorname{cm}$.
The mesh consists of cubes. 
In the following, we conduct a grid sensitivity study by varying the cube side length $\Delta \x$, starting from $2 d_p$ up to $20 d_p$, as detailed in table \ref{tab:grid_sizes}.

We test the grid with an inlet velocity of $0.001 m/s$. At this velocity, we expect to see no fluidization, therefore the particles should drop and settle in a bed.
We use the close pack volume fraction of $0.65$ and a particle diameter of $50 \operatorname{\mu m}$
to determine that we need about one million particles. %\todo{ist die gneaue Zahl von Interesse?}
To determine the bed height, probes are taken at $1000$ points at $x = 0.075\operatorname{mm}$ (middle of the domain), and on a $20 \times 50$ grid on the domain $ [0\operatorname{mm},10\operatorname{mm}] \times [0\operatorname{mm},50\operatorname{mm}]$.
In each column, the bed height is determined by the highest cell with a fluid volume fraction lower than the maximum packing fraction. We take the mean over all columns for the mean bed height.
For the coarsest grid, we observe that the simulation becomes unstable, with particles launched through the reactor multiple times, see fig. \ref{fig:mesh_study}.

The averaging used in the \MP method leads to reduced accuracy and long simulation times.

Therefore, we use this simulation as our reference to examine the convergence of the coarser grids with cell length $0.5 \operatorname{mm}$, $0.33 \operatorname{mm}$ and $0.25 \operatorname{mm}$.

\subsection{Consistency Error}
To quantify the discretization error, we use the absolute and relative $L_1$ and $L_2$ errors summed over $N$ time steps.
The absolute $L1$-error and its time-averaged counterpart are defined as
\begin{equation}
\label{eq:l1error}
    err_{L1} =\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert \qquad err_{L1,mean} = \dfrac{1}{N}\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert,
\end{equation}
and the relative $L1$-error as
\begin{equation}
\label{eq:l1relerror}
    err_{L1,rel} = \dfrac{\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert}{\sum_{i=1}^N \lvert h_{ref,i} \rvert} \qquad  err_{L1,rel, mean} = \dfrac{1}{N} \dfrac{\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert}{\sum_{i=1}^N \lvert h_{ref,i} \rvert}.
\end{equation}
Similarly, we look at $L2$-errors, which are more sensitive to outliers with the absolute $L2$-error
\begin{equation}
\label{eq:l2error}
    err_{L2} = \sqrt{\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert^2} \qquad err_{L2,mean} = \dfrac{1}{N}\sqrt{\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert^2}
\end{equation}
and the relative $L2$-error
\begin{equation}
\label{eq:l2relerror}
    err_{L2,rel} = \dfrac{\sqrt{\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert^2}}{\sqrt{\sum_{i=1}^N \lvert h_{ref,i} \rvert^2}} \qquad err_{L2,rel,mean} = \dfrac{1}{N}\dfrac{\sqrt{\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert^2}}{\sqrt{\sum_{i=1}^N \lvert h_{ref,i} \rvert^2}}.
\end{equation}

As we can see in fig. \ref{fig:l1error}, in which the $L1$-error is depicted, we can see that the error for $\Delta \x = 0.33 \operatorname{mm}$ increases rapidly during the initial fall of the particles.
In contrast, the error for $\Delta \x = 0.5 \operatorname{mm}$ rises moderately at first and later accelerates. A consistently small error is achieved by the $L1$-error for a cell length of $0.25 \operatorname{mm}$.

% \begin{equation*}

\end{equation*}

\begin{align*}

\end{align*}

The corresponding mirrored behavior can be observed for a cell length of $\Delta x = 0.5 \operatorname{mm}$, which grows moderately at first and then more rapidly.
To avoid both behaviors, we rule out both cell lengths.
The grid size $\Delta x = 0.25$ offers the best compromise between simulation costs and error. For a grid length $\Delta x = 0.25$, the simulation on average takes $11824s$ per simulation second and $19614s$ for $\Delta x = 0.2 mm$.
