\chapter{\MP method parameters and Simulation Setup}
\label{ch:simSetup}
Now that we know how the \MP method works we will setup a case to get it running. 
We will discuss which options we have in which file and which models are pre-implemented.

\section{\OF \MP method files}
\subsection{\lstinline|kinematicCloudProperties|}
The particles are modeled as a kinematic Cloud. The properties of the particles can be set in \lstinline|kinematicCloudProperties|.
Here we will look at the most important properties.

The first property we can set is the maximal Courant number \lstinline|maxCo| that is used in the Lagrangian time step fraction, see code \ref{code:stepFraction}.
The constant properties, namely the fluid density \lstinline|rho0| and \lstinline|alphaMax| are set. 
The latter is used in \lstinline|createFields| to set the minimum fluid volume fraction that is allowed per cell 
\begin{equation*}
    \fvf_{min} = 1- \fvf_{max}
\end{equation*}
used in equation \eqref{eq:maxAlpha}.
For the particles we set the Drag force model and particle injection in \lstinline|subModels|. 
In \ref{sec:MPLoop} two drag models are discussed: \lstinline|ErgunWenYu| and \lstinline|PlessisMasliyah| which will be tested in the next chapter \ref{sec:paramStudy} as they have an influence on both the fluid and the particulate phase.

Particles can be either placed inside the reactor by \lstinline|manualInjection| or 
For the first we define the particle positions in \lstinline|kinematicCloudPositions|.
For the latter we define a patch through which the particles are injected over a set time.
For both injection types we can set a particle velocity at injection and distribution for the particle diameters.
With \lstinline|nParticle| we set the number of particles in a cell.

In \lstinline|localInteraction| we define how the particles interact with the patches with the elasticity coefficient \lstinline|e| and restitution coefficient \lstinline|mu|.

The packing model defines the particle normal stress mode. In section \ref{sec:MPLoop} we discussed the explicit Harris and Crighton model.
In \OF we can also set the particle normal model to the implicit Harris and Crighton model or the explicit or implicit Lun model.
For the explicit Harris and Crighton model we can set the parameters \lstinline|alphaPacked| as the close packed volume fraction $\pvfcp$, \lstinline|pSolid| as the pressure constant $P_s$, \lstinline|beta| as the exponent and \lstinline|eps| as the small constant limiting how far away from close pack we can get.
We can also add a correction limiting method with the parameter \lstinline|e| which is given by equation \eqref{eq:correctLimiting}.
The collision damping model can be applied by setting \lstinline|dampingModel| to \lstinline|relaxation|. 
In our later simulations it is always set to \lstinline|none| and therefor not applied.

The return-to-isotropy-model is turned on by setting \lstinline|isotropyModel| to \lstinline|stochastic| and turned off by setting it to \lstinline|none|.
We set the close-pack volume for radial distribution function $g_0$ which is used in the relaxation time.
The factor \lstinline|e| determines how elastic the collision is, see $\eta$ in \eqref{eq:DampingTimeG}.
The impact of the parameters and the dependence of the simulation on the parameters is discussed in chapter \ref{ch:results}.

\subsection{Boundary conations}
Inlet is an interstialVelocityInlet which scales the inlet velocity with the volume fraction of air:
\begin{equation*}
    \u_{inlet} = \dfrac{\u}{\fvf}
\end{equation*}
The pressure of the inlet is set to \lstinline|fixedFluxPressure|.
The front and the back are connected through \lstinline|symmetry|.


\subsection{Grid}
The highest mean bed height from the data is about $2.4 \operatorname{cm}$. 
To include inflections from the particle we roughly double the height for the simulation using $5 \operatorname{cm}$ as the height of our mesh.
The width of our simulation mesh is adapted to the simplified fluidized bed with $1 \operatorname{cm}$.
For the following mesh study, where we tested grid sizes of two times particle diameter up to twenty times, we use a depth of $1\operatorname{mm}$.

For a velocity of $0.001 m/s$ we expect to see no fluidization therefor the particles should drop and lay in a bed.
For the simulation we use a close pack volume fraction of $0.65$.
Because the \MP method only models particles as point masses we can determine that we need approximately one million particles for a bed height of $1 \operatorname{cm}$.
Here the diameter of the particles is $0.00005\operatorname{m}$.
In figure \ref{fig:mesh_study} we can see that for a grid size of $1 \operatorname{mm}$ the particles are flung through the reactor multiple times.

The behavior is less prevalent for a grid size of $0.5 \operatorname{mm}$ but still occurs at later time steps.
For a cell length of $0.1 \operatorname{mm}$ we can see that the cells are too small for the number of particles.
Because the \MP averages over the number of particles in a cell the simulation becomes less accurate.
The simulation was aborted after three days of simulation time.
The bed height of at the last time step is exactly $1 cm$ for a cell length of $0.2 \operatorname{mm}$.
We use this as a reference to examine the convergence behavior for the cell length $0.5 \operatorname{mm}$, $0.25 \operatorname{mm}$, $0.33 \operatorname{mm}$.

In the following we look at the mean absolute $L1$-error
\begin{equation}
\label{eq:l1error}
    err_{L1} =\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert \qquad err_{L1,mean} = \dfrac{1}{N}\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert
\end{equation}
the relative $L1$-error
\begin{equation}
\label{eq:l1relerror}
    err_{L1,rel} = \dfrac{\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert}{\sum_{i=1}^N \lvert h_{ref,i} \rvert} \qquad  err_{L1,rel, mean} = \dfrac{1}{N} \dfrac{\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert}{\sum_{i=1}^N \lvert h_{ref,i} \rvert}.
\end{equation}
We also look at the $L2$-error which is more sensitive to outliers.
We use the absolute $L2$-error
\begin{equation}
\label{eq:l2error}
    err_{L2} = \sqrt{\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert^2} \qquad err_{L2,mean} = \dfrac{1}{N}\sqrt{\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert^2}
\end{equation}
and the relative $L2$-error
\begin{equation}
\label{eq:l2relerror}
    err_{L2,rel} = \dfrac{\sqrt{\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert^2}}{\sqrt{\sum_{i=1}^N \lvert h_{ref,i} \rvert^2}} \qquad err_{L2,rel,mean} = \dfrac{1}{N}\dfrac{\sqrt{\sum_{i=1}^N \lvert h_i - h_{ref,i} \rvert^2}}{\sqrt{\sum_{i=1}^N \lvert h_{ref,i} \rvert^2}}.
\end{equation}

For the $L1$-error depicted in figure \ref{fig:l1error}. 
during the initial fall of the particle the error for a cell length of $0.33 \operatorname{mm}$ grows rapidly.
Afterward the mean absolute error levels out as the absolute error grows linearly.
On the other hand the error for a cell length of $0.5 \operatorname{mm}$ only grows moderately at first. After the first initial fall the error starts to grow more rapidly.

The absolute $L1$ error for the cell length of $0.5 \operatorname{mm}$ grows moderately at first.

We can now look at the stationary accuracy. We use the relative $L1$ error computed over the entire five seconds, see figure \ref{fig:statL1}.
We can estimate the order of convergence by
\begin{equation*}
    EOC =\dfrac{\lvert L1_{0.25}- L1_{0.33} \rvert}{\lvert L1_{0.33}- L1_{0.5} \rvert} = \dfrac{\lvert 0.00498634584254441-0.022492365778959397 \rvert}{\lvert 0.022492365778959397-0.03705231627423083\rvert}\approx 1.2.
\end{equation*}
We note that due to the averaging methods applied the error grows for smaller cell lengths. We can see this behavior for $\Delta \x = 0.1 \operatorname{mm}$.
